# Appendix C: Visual Synthesis

The source presentation compresses the operational argument of this book into twelve plates, and
they are reproduced here at full size because they are useful in a way the chapters are not. A
chapter is something you read once, while a plate is something you can put on a screen during a
design review and argue over, which is what these were built for.

Use them for dashboard design, for review meetings and for planning a rollout. Chapter 15 is the
written version of the same argument, so if a plate raises a question, that is where the answer
is set out at length.
