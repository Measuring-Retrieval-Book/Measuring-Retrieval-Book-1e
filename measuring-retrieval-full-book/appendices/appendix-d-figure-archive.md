# Appendix D: Source Figure Archive

Not every figure in the source material found a home in a chapter. Some were section openers for
installments that were merged during assembly, and some illustrated points that are now made in
the prose instead, so they would have been lost had they not been collected here.

This archive holds those figures, preserving the original sketches, formulas, summary boards and
decision maps along with the source file and line each one came from. The diagram ledger records
the same provenance for every figure in the book, and this appendix is the part of it you can
actually look at.
